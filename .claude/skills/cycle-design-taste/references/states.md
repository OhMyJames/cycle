# 状态

一块界面只画了"正常"就没有做完。下面每块都要有这些状态的画面,并在界面测试里各有一条(`packages/ui/test/browser/app.browser.tsx`,`bun run test:browser`)。

通用的六种:**空**、**加载**、**出错**、**断线或重连**、**内容很长**、**数量很多**。

## 逐块(对齐 `DESIGN.md` 第 4 层范式)

| 块 / 范式 | 要看的状态 |
|---|---|
| 工作位置与工作区切换(location-bar / workspace-switcher) | 已连接、连接中、重连中、连不上(带 ssh/系统原话 + Retry)、没有远程工作位置、多个工作位置分组、其他工作区有紧急角标、工作位置名/目录名很长 |
| 会话列表(sidebar / session-list) | 空(附就地 New session 入口)、几百个(展开/收起及切换工作区重置)、标题很长、标题为空(多条同目录未命名会话)、Needs you、Running、Background、Unread、已归档、刚删除、侧栏折叠与主区恢复按钮 |
| 空白新建会话(blank) | 默认带入工作区、目录为空、手输路径、Browse 选择(本地/远程)、无可用 agent(附原因与下一步)、配置读取失败(Retry)、信任文件夹确认、首条消息发送中/建会话失败退回 |
| 对话(conversation) | 空(附引导)、加载历史、很长的历史(增量上拉与回到底部)、流式中、被取消、出错结束(附就地 Retry)、断线中、只有思考没有回答、单工具升格为多工具卡片 |
| 消息 | 很长的单词或路径、宽表格、超长代码行、很多列表项、不安全的链接和图片(已有拦截说明)、用户/代理消息与代码复制 |
| 工具卡(tool / work) | 进行中、完成、失败(默认展开并写出 failed)、输入很长、输出很长、没有输出、被取消 |
| 权限卡(permission) | 一个请求、同时多个、命令很长、`⌘Return` 全局快捷批准、在别处已被回答(自动关闭)、断线禁用态 |
| 计划(plan) | 没有、全部待办、部分完成、全部完成、条目很长 |
| 输入框(composer) | 空、多行、很长、附件图片/超限报错、排队与插话(steer)、断线草稿保留、窄视口(480px)工具条折行、危险权限模式(免确认)警示 |
| 弹窗与表单(dialogs / connectors) | 打开(首个输入自动聚焦)、Enter 提交、校验出错、提交中、提交失败(带原因)、破坏性确认(`destructive` 主按钮且焦点在 Cancel)、添加与编辑工作位置、移除工作位置确认、Esc 关闭并归还焦点 |
| 更新与横幅(update / banner) | 没有更新、检查中、可用、差分下载中、安装中、失败(带原因)、已禁用、远端 daemon 版本过旧及手动升级命令 |
| 设置表单(config-form / setting-chips) | 没有可设置项、很多项、未记录项(`Not set`)、值来自 agent 而非索引(待回显) |

## 出错与空状态的画法

- **错误三要素**:发生了什么 + 等宽可选择的系统/远端原话(换行,不隐藏) + 明确的下一步按钮(`Retry`、编辑工作位置、重读)。出错位置就在出问题的那一块,不要只弹一个会自动消失的 toast。
- **空状态必须有出口**:无会话时写清下一步并提供能直接点击的 `New session` 按钮;无可用 agent 时说明可能原因(如凭证未配置或二进制缺失)和排查入口,不留死胡同。

## 极端数据

做完先用极端数据看一遍:一个 200 字符的标题、一个 500 字符没有空格的路径、一个 3000 行的输出、一个 800 个会话。
标题末尾淡出(`--cycle-fade-end`),路径优先保留尾部项目/文件名,代码块与表格各自横向滚动,不能撑破侧栏或让整个页面出现横向滚动条。
