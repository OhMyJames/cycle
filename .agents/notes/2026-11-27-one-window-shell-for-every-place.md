# Agent Note: 窗口只有一个外壳，设置和 Connectors 是外壳里的地方，不再整窗覆盖

Status: accepted
Date: 2026-11-27
Basis: 2026-11-27 负责人在对前端代码量和抽象的盘点后确认（CYC-530）：设置、Connectors 并入统一外壳；侧栏顶行和底部固定、动作区和主体由地方决定；不要前进后退历史；分两步推进，允许顺带统一视觉。

## Problem

窗口里原有三套各自成立的外壳。会话画在 `SplitLayout` 里；设置和 Connectors（CYCL-78、CYCL-82）在 `SplitLayout` 之外盖住整窗，`PageLayout` 按 `--cycle-sidebar-width` 仿画一条侧栏（`page-nav`），为了"侧栏边界和标题栏不动"（CYCL-219）要在 CSS 里让两者对齐；Loop（CYC-500）又是侧栏的一种模式。标题栏写了 3 处、页头写了 5 处，折叠按钮作为 prop 一层层传进各个页头，提示条的顺序、Esc 与焦点回跳、埋点在 `usePages` 里为每个页面各写一套。重复的行数不多，问题是每加一个地方都要把这些再写一遍，改一次标题栏要改几处，并且容易漏。

## Decision

- 窗口只有一个外壳（`packages/ui/src/react/shell.tsx` 的 `AppShell`）。所有地方都一样的部分由它画：侧栏顶行与折叠按钮、侧栏底部（应用通知、账号菜单）、主区标题栏（高度、红绿灯避让、拖动区、侧栏收起时的展开按钮）和标题栏下提示的顺序。
- 显示什么由一个带类型的状态决定（`app-pages.ts` 的 `Place`：会话、Loop、设置、Connectors），不引入 router，没有历史；每个地方记住上次的分区或视图。
- 地方从自己内部说出它在侧栏、标题、标题栏动作、提示里的部分（`ShellSidebar` / `ShellTitle` / `ShellTools` / `ShellNotices`，用 React portal 画到外壳的位置）。这样一个组件的状态可以跨两栏：设置页的分区仍是 SDK 的一个 `Tabs`，分区列表在侧栏里，分区内容在主区，方向键和 tab 语义不变。
- 设置和 Connectors 不再整窗覆盖，仿画的侧栏删除；侧栏在页面里也能拖宽、折叠。页面回到打开它的地方（会话或 Loop），所以页面带着 `base`，返回行在 Loop 下写 `Back to Loop`。
- 会话与 Loop 共用侧栏动作区，是外壳上的同一组元素，切换模式时焦点不丢。
- 已在 CYC-530 实现。

## Alternatives considered

- **只把标题栏抽成共用组件，设置和 Connectors 仍整窗覆盖**：改动小，但侧栏顶部会一直有两份，CYCL-219 的"不动"继续靠 CSS 对齐维持。负责人选了并入统一外壳。
- **地方以 props 交出侧栏、标题和正文的节点，由外壳摆放（不用 portal）**：设置页的分区列表和分区内容属于同一个 `Tabs`，分开交出就要把 `Tabs` 换成按钮加 `aria-current`，丢掉方向键切换和现有的 tab 语义（大量测试按 `role="tab"` 找分区）。用 portal 保留了它们。
- **每个地方各自画侧栏动作区**：会话和 Loop 的切换按钮在两个地方是两组元素，按下 Loop 后焦点落在一个随即被隐藏的按钮上，键盘用户会丢焦点。改为外壳上的同一组。
- **页面一律回到会话**：最初写在需求里；但原来从 Loop 打开设置再返回会回到 Loop，一律回会话是行为退化，所以改为回到打开它的地方。
- **前进后退历史（⌘[ / ⌘]）**：负责人不要；状态模型更简单。

## Consequences

- 新增一个地方：在 `Place` 里加一个分支，写一个用 `Shell*` 部件的组件，在 `app.tsx` 里挂上；不再另画标题栏、侧栏顶部、提示顺序或折叠按钮。改标题栏只改 `shell.tsx` 和 `main.css` 的 `main-header`。
- 主区标题栏一直存在（没有会话、侧栏展开时也有 42px 的空标题栏），所以空状态比原来低半个标题栏；设置和 Connectors 的侧栏现在有折叠按钮、应用通知和账号菜单。
- portal 的代价：外壳的目标元素要先进页面，地方才画（`AppShell` 在目标都有之后才渲染地方，回调 ref 在提交阶段设置，不会闪）；依赖 DOM 包含关系的逻辑（Esc 是否属于页面、初始焦点）要按侧栏和主区判断，而不是按地方的根元素。
- `⌘B` 在所有地方都可用；设置和 Connectors 里只放行 `⌘K`、`⌘N`、`⌘B` 和 `⌘,`。
