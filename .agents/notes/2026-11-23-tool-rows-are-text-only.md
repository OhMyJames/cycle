# Agent Note: 工具行只有文字，不画任何图标

Status: accepted
Date: 2026-11-23
Basis: CYCL-139。负责人 2026-11-23 看了 0.3.17 的对话后要求：工具调用展开、收起，任何时候都不显示图标，纯文字，用次要文字色，并参照对方产品的对比度调次要色。
Supersedes: [完成的工具行，行首用类型图标](2026-11-23-finished-calls-lead-with-their-kind.md)

## Problem

0.3.17 的工具行左边一列有类型图标、圆点、转圈、红叉，右边悬停有展开箭头；文字用 `--cycle-ink-secondary`，但它在深色下是 `#c7c7cc`，和正文 `#f5f5f7` 只差 1.55:1，看起来和回复一样亮。一轮里工具行一多，图标和亮字让过程抢了回复的注意力。对方产品的做法是一行灰色文字，没有图标。

## Decision

- 工具行、工作卡、子 agent 行都不画图标：没有类型图标、圆点、转圈、红叉，也没有展开箭头。
- 状态靠文字说：在跑的是动词进行时（Running…）加计时，失败的是红字加 `failed`，没跑完的写 `unfinished`。能展开靠悬停底色和 `aria-expanded`。
- 一行没有动词时态能说"在跑"的时候（agent 的 description、还在等批准的、子 agent、工作卡里正在跑的那个有 description），行尾用文字写状态（`in progress`、`pending`）。
- 工作卡展开后，子行缩进 1.5rem（和行展开内容同一级），左边一条细竖线；竖线原来串的是行首图标，现在挂在缩进上。
- 次要色调暗：浅色 `#454549` → `#505055`，深色 `#c7c7cc` → `#a8a8ae`，正文对次要文字约 2.2–2.3:1。对方产品的灰对底只有约 4.2:1，低于本项目 4.5:1 的底线，所以没有照抄，只往那个方向走；次要色在所有表面上仍 ≥ 5.9:1。这是全局令牌，引用、思考、侧栏平时行等用次要色的地方一起变暗。
- 进度行（StepLine）的转圈不在这次范围：它不是工具行，是"agent 正在做什么"的状态。

## Alternatives considered

- **只去掉类型图标，保留转圈和红叉**：状态最快被看到，但负责人要求任何时候都没有图标。
- **工具行用 `ink-muted`**：更接近对方产品的灰，但负责人指定次要色；muted 留给元信息和命令摘要，这样行内动词和命令仍有区别。
- **照抄对方的灰（约 4.2:1）**：低于 4.5:1 的文字底线，没用。

## Consequences

- 一眼看左边一列不再能找到"在跑/失败"的行，要读文字或看红色。
- 深色下次要色和 muted 只差约 1.2:1：行里的动词（次要色、正文字体）和命令（muted、等宽）主要靠字体区分。
- 加新的工具类型不用再选图标。
- 次要色变暗影响所有用它的地方；以后加用次要色的文字，按新的对比度看。
