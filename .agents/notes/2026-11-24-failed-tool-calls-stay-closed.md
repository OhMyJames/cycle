# Agent Note: 失败的工具调用不自己展开

Status: accepted
Date: 2026-11-24
Basis: 负责人 2026-11-24 反馈：有失败的工具调用时自动展开，体验差，不需要自动展开。

## Problem

原来工具行和工作卡在含有失败时默认展开，失败在屏幕上到达时也会自己展开（`useOpenOnFailure`），理由是"失败是人来读的"。实际上 agent 大多会自己处理掉失败（重试、换个命令），自动展开把一大块命令和输出塞进对话，打断阅读，也和"过程不抢回复"（CYCL-139）相悖。

## Decision

- 工具行、工作卡不管什么状态都默认收起；失败到达时不改变人已经设好的开合。
- 失败仍然一眼可见：行头红字写 `failed`，工作卡那行写"N failed"；点开才看命令和输出。
- 没正常结束的回合，最后一段里的失败仍单独成行放在回合下面（`model/blocks.ts`），同样收起：回合尾已经说了怎么结束的。
- 从 Overview 要求显示某个调用时，所在的卡照旧展开（`useRevealOpen`），那是人主动要看的。

## Rejected

- **失败默认展开 / 到达时自动展开**：就是这次去掉的做法，别再加回来。
- **只让导致回合停下的那一行展开**：回合尾已有错误说明，那一行也写着 failed，再展开收益小，还要多一种规则。
